# My_Learning_Platform

> 🚧 **Work in progress** – This project is still in progress. 

A small pixel-art quiz website to help students learn and practice their knowledge about IT and networking. Answer the questions, see right away if you got it right, and get your score at the end.

# Features
- Multiple-choice questions about IT and networking
- Progress indicator (e.g. Question 1 of 3)
- Instant feedback: green for a correct answer, red for a wrong one
- Final score at the end of the quiz
- Restart button to try again
- Cute pink pixel-art design (pixel borders, drop shadows, grid background)

# Built with
- HTML – page structure
- CSS – pixel-art style (pixel borders made with `box-shadow`, CSS variables, flexbox)
- JavaScript – quiz logic (questions, answers, score, restart)
- [Geist Pixel](https://fonts.google.com/) font
